# 🧡 TECH STACK: SVELTEKIT
- **Runtime:** Node.js 24 (Active LTS), TypeScript strict.
- **Framework:** SvelteKit (Svelte 5, `+server` endpoints).
- **Validation:** Zod.
- **Database:** PostgreSQL + pg.
- **Testing:** Vitest + Playwright.
- **Linting:** ESLint + `sv check`.
- **Package manager:** pnpm.
- **Version Control:** Git.
