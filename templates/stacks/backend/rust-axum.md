# 🦀 TECH STACK: RUST AXUM
- **Runtime:** Rust 1.97+ (edition 2024).
- **Framework:** Axum 0.8 on Tokio.
- **Validation:** serde + explicit validation in the application layer.
- **Data access:** sqlx (compile-time checked queries, migrations with `sqlx migrate`).
- **Database:** PostgreSQL + sqlx.
- **Testing:** `cargo test`.
- **Linting:** rustfmt + clippy + cargo audit.
- **Package manager:** cargo.
- **Version Control:** Git.
