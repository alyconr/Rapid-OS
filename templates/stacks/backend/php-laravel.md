# 🐘 TECH STACK: PHP LARAVEL
- **Runtime:** PHP 8.4 (Laravel 13 supports PHP 8.3 to 8.5).
- **Framework:** Laravel 13.
- **Validation:** Form Requests.
- **ORM:** Eloquent (migrations with `php artisan migrate`).
- **Database:** MySQL + pdo_mysql.
- **Testing:** Pest or PHPUnit (`php artisan test`).
- **Linting:** Laravel Pint + PHPStan + Deptrac.
- **Package manager:** Composer.
- **Version Control:** Git.
