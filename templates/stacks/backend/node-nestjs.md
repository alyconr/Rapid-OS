# 📦 TECH STACK: NODE NESTJS
- **Runtime:** Node.js 24 (Active LTS), TypeScript strict.
- **Framework:** NestJS (latest stable major per github.com/nestjs/nest/releases).
- **Validation:** class-validator + ValidationPipe (or a Standard Schema library such as Zod).
- **ORM:** TypeORM / Prisma / Drizzle (migrations required).
- **Database:** PostgreSQL + pg.
- **Testing:** Vitest (ESM) or Jest (CommonJS) with `@nestjs/testing` and Supertest.
- **Linting:** oxlint + Prettier.
- **Package manager:** pnpm.
- **Version Control:** Git.
