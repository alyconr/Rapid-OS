# 🟣 TECH STACK: DOTNET ASPNETCORE
- **Runtime:** .NET 10 (LTS), C# nullable enabled.
- **Framework:** ASP.NET Core 10 (Minimal APIs).
- **Validation:** FluentValidation or DataAnnotations.
- **ORM:** Entity Framework Core (migrations with `dotnet ef`).
- **Database:** PostgreSQL + Npgsql.
- **Testing:** xUnit + `Microsoft.AspNetCore.Mvc.Testing` (`dotnet test`).
- **Linting:** dotnet format + analyzers + NetArchTest.
- **Package manager:** NuGet.
- **Version Control:** Git.
