# 🟪 TECH STACK: KOTLIN SPRING BOOT
- **Runtime:** Kotlin 2.2+ on Java 17+ (Spring Boot 4.1 requires at least Java 17).
- **Framework:** Spring Boot 4.1 with Spring Modulith.
- **Validation:** Jakarta Bean Validation.
- **ORM:** Spring Data JPA / JDBC (migrations with Flyway or Liquibase).
- **Database:** PostgreSQL + pgjdbc.
- **Testing:** JUnit 5 + Spring Boot test slices (`./gradlew test`).
- **Linting:** ktlint + OWASP Dependency-Check.
- **Package manager:** gradle.
- **Version Control:** Git.
