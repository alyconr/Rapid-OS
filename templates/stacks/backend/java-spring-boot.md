# ☕ TECH STACK: JAVA SPRING BOOT
- **Runtime:** Java 17+ (Spring Boot 4.1 requires at least Java 17 and supports up to Java 27).
- **Framework:** Spring Boot 4.1 with Spring Modulith.
- **Validation:** Jakarta Bean Validation.
- **ORM:** Spring Data JPA / JDBC (migrations with Flyway or Liquibase).
- **Database:** PostgreSQL + pgjdbc.
- **Testing:** JUnit 5 + Spring Boot test slices (`./mvnw test`).
- **Linting:** Checkstyle + OWASP Dependency-Check.
- **Package manager:** maven.
- **Version Control:** Git.
