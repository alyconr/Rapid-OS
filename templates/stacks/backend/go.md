# 🐹 TECH STACK: GO
- **Runtime:** Go 1.27 (the two latest majors are supported).
- **Framework:** net/http (standard library) with the Go 1.22+ routing patterns.
- **Validation:** explicit validation in the application layer.
- **Data access:** database/sql + pgx / sqlc (migrations with golang-migrate or goose).
- **Database:** PostgreSQL + pgx.
- **Testing:** `go test ./...`.
- **Linting:** gofmt + go vet + govulncheck.
- **Package manager:** Go modules.
- **Version Control:** Git.
